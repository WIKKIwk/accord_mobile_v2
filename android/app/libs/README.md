# XPrinter Android SDK

`printer-lib-3.5.8.aar` is the official XPrinter Android SDK binary downloaded
from the vendor support page for 58/80 mm and 2/3-inch label printers:

https://www.xprinter.net/companyfile/1/


The vendor archive did not include a standalone redistribution license. Confirm
distribution terms with XPrinter or the printer supplier before publishing an
APK that contains this binary.
